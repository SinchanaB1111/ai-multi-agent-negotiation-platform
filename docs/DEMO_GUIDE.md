# Milestone 3 Demo Flow

## 1. Simulation Mode
1. Select **Simulation Mode**.
2. Select one of the three scenarios.
3. Customize both agent personas.
4. Review the setup.
5. Start the negotiation.
6. Show the live Arena: round, status, offers, transcript, strategy, decisions and concessions.
7. Wait for agreement/deadlock.
8. Click **View Outcome & Download Report**.
9. Demonstrate HTML report, TXT summary and JSON transcript export.

## 2. Practice Mode
1. Return to the scenario page.
2. Select **Practice Mode**.
3. Select a scenario and configure both sides.
4. Start the Arena.
5. Enter an offer as Agent 01.
6. Show the AI opponent evaluating the offer and producing ACCEPT, REJECT or COUNTER behavior.
7. Continue until agreement, rejection or deadlock.
8. Download the report from the completion panel.

## 3. Three Scenarios
- Vendor Pricing Negotiation
- Job Offer Negotiation
- Project Budget Allocation

## 4. Demo-safe behavior
The system keeps a rule-based decision layer as a safety path when LLM providers are unavailable. This keeps the Arena demonstrable instead of failing because of an external model quota or temporary provider outage.
